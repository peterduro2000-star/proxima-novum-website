# Assets Directory

Place all your image assets here. Recommended naming convention:

- `favicon.png`: Website favicon.
- `og-image.png`: Open Graph image for social sharing (1200x630).
- `tailorpro-icon.png`: App icon for TailorPro.
- `tailorpro-screenshot1.png`: Main screenshot for TailorPro.
- `tilemate-icon.png`: App icon for Tilemate.
- `tilemate-screenshot1.png`: Main screenshot for Tilemate.
- `roofmate-icon.png`: App icon for RoofMate.
- `roofmate-screenshot1.png`: Main screenshot for RoofMate.
- `poultrypro-icon.png`: App icon for Poultry Pro.
- `poultrypro-screenshot1.png`: Main screenshot for Poultry Pro.
